# NoteApp

NoteApp — это веб-приложение для личного управления заметками. Оно позволяет создавать, редактировать, удалять заметки, распределять их по категориям и отслеживать свою активность. Проект создан для изучения ASP.NET Core MVC и Entity Framework Core.

## Технологии

- C# / .NET Core (версия)
- ASP.NET Core MVC / WPF
- Entity Framework Core
- PostgreSQL

## Как запустить

1. Клонируйте репозиторий: `git clone ...`
2. Откройте решение в Visual Studio (файл `.sln`).
3. Восстановите пакеты NuGet (обычно автоматически).
4. Обновите базу данных: `dotnet ef database update`
5. Запустите проект (F5).

## Функциональность

- Добавление, редактирование, удаление записей
- Разделение категорий
- Фильтрация по дате
- Сохранение данных в БД
- Просмотр статистики
